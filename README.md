# An app to show various timers in the macOS menu bar.
This app is a replacement for a similar, but not longer maintained, app, that I was using before, with a few features added that I wanted for my personal use.
- Available timer types: single timer, stopwatch, timer-group where only a single timer is active at a time.
- Presets and timer state are saved between app launches.
- Timers in the menu bar can be started/stopped by option-clicking.
